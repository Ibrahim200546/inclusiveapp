## Прохождение

- Ученик выбирает занятие и нажимает «Тыңдау». Ответ становится доступен после полного прослушивания. Следующие вопросы к тому же тексту используют уже прослушанный образец; повтор сохраняет вопрос.
- Длинную озвучку можно поставить на паузу, продолжить и остановить. Пауза не считается выполненным прослушиванием. Возобновлённое аудио возвращается в общий реестр звука приложения; общая остановка и переход в другой раздел работают. Поздний отказ старого возобновления не отменяет новую запись.
- Неправильный ответ сохраняет текущий шаг. Правильный блокирует повторное начисление; переход выполняется кнопкой «Келесі».
- Для пар идут этапы «Буындар → Сөздер → Сөйлемдер», по два образца на этап. Во 2–4 классах используются отдельные поднаборы: нерасшифрованные группы и сомнительные буквы не добавлялись по догадке.
- Восстановление текста/четырёх иллюстрированных сцен работает кнопками вверх/вниз. Есть полный эталон порядка. Сцены нарисованы локальным SVG с пиктограммами и подписями, без внешнего сервиса картинок.
- В математике выбор операции и вычисление — отдельные шаги. «2-ге артық» не подменяет «2 есе артық». Умножение содержит все 64 сочетания 2–9; деление только с целочисленным ответом.
- В устной практике исполнение отмечает педагог. Для интонации, силы голоса и специальных акцентов требуется живой образец педагога. Синтетическое чтение текста не выдано за проверенный образец нужной интонации или шёпота. Микрофон и запись голоса не требуются.
- «Бірге / Өздігінен» отображаются в устной работе и сохраняются отдельно. При открытии текста помощи использование поддержки учитывается в результате. Итог разделяет ответы выбора и отметки педагога.
- Результаты хранятся локально для текущего пользователя/гостя, ключ содержит класс, таблицу, направление, исходные коды и ID занятия. Незавершённое занятие возобновляется с неотвеченного шага; после повторного входа образец требуется прослушать заново. Синхронизация этих подробных результатов через Supabase не заявляется.

## Исправления совместимости

Новый модуль сам переводит свои кнопки, а казахский учебный текст защищён от подстановок общего словарного переводчика. В `i18n-profile.js` добавлена поддержка `translate="no"` / `data-i18n-managed`; остальные экраны продолжают использовать прежний переводчик. Версия скрипта в HTML повышена до 7.

При переходе между верхними меню и заданиями прокрутка возвращается к началу. Мобильная верстка учитывает фиксированные верхние/нижние кнопки и оставляет справа место для глобальных помощников. Основные радиальные меню не заменены. React routing, Supabase auth, native Android/Electron/iOS и фонемная модель не менялись.
