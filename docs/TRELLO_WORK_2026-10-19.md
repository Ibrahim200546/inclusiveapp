## Реализовано локально

### 02 — «Санды тап»

В меню 0–1 классов добавлен радиальный вход «Тыңдап үйрен», внутри — «Санды тап» и четыре акустических упражнения. Выбор 0/1 на экране модуля разделяет сохранённые результаты.

Десять крупных кнопок, десять вопросов без повторения чисел внутри цикла. При неправильном ответе вопрос сохраняется; повтор проигрывает тот же файл. Ответ доступен после завершения аудио. Следующий вопрос открывается по «Келесі». Повторные быстрые нажатия не начисляют результат дважды. Итог показывает число выполненных вопросов и попыток. Новое прохождение сбрасывает состояние; последний вопрос прошлого цикла не становится первым нового.

20 встроенных MP3: инструкции 1–10 на казахском и русском. Упражнению не нужен сетевой TTS. Источник — действующий API Edu CoreX, синтетическая озвучка; это не запись носителя. Текст и файлы перечислены в `public/original/sounds/find-number/manifest.json`. Для русских файлов использован поддерживаемый голос `zhanar_ru`: текущий опубликованный сервер с голосом по умолчанию `alena` возвращает ошибку на казахстанском endpoint. Локально исправлен региональный выбор голоса в `api/tts.js` и Vite: для Казахстана `zhanar_ru`, для глобального fallback сохранён `alena`; явная настройка/параметр имеют приоритет. Production этой работой не изменялся.

### 06 — базовые акустические упражнения

Реализованы количество сигналов 1/2/3, выбор из двух ритмических образцов, быстрый/медленный темп и низкий/средний/высокий тон. Используются явно синтетические сигналы Web Audio, а не записи хлопков, инструментов или человеческого голоса. Повтор сохраняет события, интервалы, частоту и длительность. В сравнении ритмов можно прослушать оба варианта перед выбором. Высота меняется при одинаковой длительности; темп — при одинаковой частоте. Выход останавливает текущий сигнал.

Настройки для прослушивания педагогом: количество — 440 Гц, 140 мс, интервал 600 мс; темп — три сигнала с интервалом 300/800 мс; высота — 220/440/880 Гц, 800 мс; цифровая амплитуда 0.12 с плавными фронтами. Это предложенные настройки реализации, не цитата программы. Вальс/марш, направление и более сложные ритмы не подменены имитациями; для них нужны утверждённые материалы.

## Прогресс и совместимость

Новые подробные результаты хранятся локально для текущего пользователя/гостя в `eduCorex.learning.v1:<user-id|guest>`; ключ навыка включает класс, таблицу, контекст и ID упражнения. Синхронизация подробных результатов через Supabase не добавлялась: в проекте не найдено соответствующей таблицы. Завершение числового/акустического цикла вызывает существующую награду один раз. Отказ localStorage не блокирует упражнение; результат остаётся на экране.

React-маршруты, Supabase auth, native-конфигурации Android/Electron и модель распознавания фонем не изменялись. Новые обработчики дополняют существующую legacy-архитектуру. Отдельно устранена отмена новой озвучки при повторном применении **того же** языка после перехода между экранами.

Добавление пункта сохраняет радиус исходного голосового меню. Подписи нового меню проверяются целиком по ширине экрана. Для короткого мобильного экрана уменьшен верхний отступ; для тёмной темы числового/акустического задания добавлен контрастный фон. Сохранены существующие глобальные помощники и нижняя навигация.
