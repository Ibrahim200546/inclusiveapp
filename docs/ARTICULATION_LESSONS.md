## Артикуляция

Три оригинальные векторные анимации, без сторонних изображений и видеосервисов:

1. **Тіс тазалау** — язык движется по внутренней стороне верхних, затем нижних зубов.
2. **Доп** — губы сомкнуты, щёки надуваются попеременно, воздух переходит между ними.
3. **Төбешік** — кончик языка остаётся у нижних зубов, середина поднимается; движение показано в боковом разрезе.

Есть запуск, пауза, повтор, перемотка, скорости 0.5×/0.75×/1× и переход между уроками. По умолчанию изображение неподвижно. При reduced motion используются ключевые кадры. При выходе анимация уничтожается, при смене языка сохраняются положение и воспроизведение.

Движения и текст основаны на приложенном пользователем образце. Это визуальные учебные демонстрации; автоматической проверки выполнения ртом или микрофоном нет.

## Жоғалған Қ

Три задания с собственными SVG-животными: **Қасқыр, Қоян, Тасбақа**. Нужно вернуть Қ в пропуски слова. Неверный выбор позволяет попробовать ещё раз; после верного ответа животное анимируется. Переход явный, награда выдаётся один раз после трёх заданий.

## Күзгі оқиға

Аудиозапись WhatsApp расшифрована локальной Whisper-моделью. Она не отправлялась в API и не включена в сайт; машинный текст содержит ошибки и не считается дословной стенограммой. Надёжно выделены тема осени, фразы **«Күз келді»**, **«Күн суытты»** и визуальное сопровождение предложений. Третья фраза **«Жапырақтар түсті»** — авторский тематический пример.

В каждом из трёх заданий есть анимационная сцена с ребёнком и три подписанные иллюстрации для выбора. Поддерживаются русский и казахский языки, повторная попытка без штрафа и однократная награда.

Озвучка подключена к существующему `appTts` через дополнительную карту локальных файлов. В приложение включены **девять MP3**: три казахских названия животных и по три осенних предложения на казахском и русском. Для этих фраз TTS API при воспроизведении не требуется. Нажмите «Сөзді тыңдау» или «Сөйлемді тыңдау»; кнопка занята до конца клипа. При переходе, выходе или смене языка осенней игры текущая речь останавливается; запоздалый результат не меняет новый экран.

Это синтетическая озвучка собственного учебного текста, созданная через существующий серверный TTS сайта. Пользовательская запись WhatsApp в звуковые материалы не включена. Для русских клипов явно выбран доступный в регионе голос `zhanar_ru`, см. [официальную таблицу голосов](https://yandex.cloud/ru-kz/docs/speechkit/tts/voices). `manifest.json` содержит текст, язык, запрошенный голос и SHA256 клипов; секретов в нём нет.
