# Local selected-letter recognition

The voice/train exercise now calls `TrainPhonemeSession`, not the standalone VAD session. It first recognizes phones without the selected letter being passed into the model, then compares all nonblank phones with that selection. Confident competing consonants, dominant competing output and empty recognition receive no reward. Low-confidence incidental events no longer veto an otherwise supported selected phoneme. Model softmax peaks are heuristic confidence evidence, not measured pronunciation accuracy. The score uses selected-phone confidence and its share of noncarrier evidence; carrier vowels are permitted for stop consonants. For stop consonants, a carrier vowel is allowed; long mode requires three recognized target bursts. For vowels, short mode requires the recognized selected phoneme; long mode additionally requires 2 seconds measured voiced duration. CTC frame labels are not duration alignment.

Audio stays in transient browser/worker memory and is zeroed after processing. Only public model weights/configuration may be downloaded. No audio request, audio file, API key or speech server is used. The microphone closes before inference and on stop/navigation/visibility changes. Inference runs in a worker. Loading and recognition errors never fall back to success from sound level.

Runtime: bundled Transformers.js 3.8.1 (Apache-2.0) and ONNX Runtime WASM; lazy loaded from `public/original/vendor/phoneme`. Model: `qnighy/wav2vec2-xlsr-53-espeak-cv-ft-ONNX`, pinned revision `d2987af7ae07d53eafee15dc7190479062faa1e8`, q4 241,430,967 bytes, Apache-2.0; derived from Meta XLSR53 espeak. Local downloaded weights/configuration are in ignored `public/original/models/phoneme`. When absent, the worker downloads this pinned public model and browser-caches it. Existing local builds include the local weights; Git does not include them. This adds about 22 MB bundled runtime and, if present, 241 MB local model to build output. No package dependency was added.

This is experimental phoneme detection, not validated clinical pronunciation scoring. Kazakh vowel recognition is inconsistent; uncertain/mismatched outputs are rejected rather than overridden. The full recording may take several seconds to analyze on CPU. Capture matches the successful local QA page: prompt only after the first actual microphone block, an 8-second speaking window, RMS 0.006 silence trimming with 300 ms margins and at most 5 seconds sent into local inference; start speaking after the microphone prompt. User confirmation of real microphone behavior in this integrated exercise is still needed before commit.

Primary sources: https://huggingface.co/qnighy/wav2vec2-xlsr-53-espeak-cv-ft-ONNX and https://huggingface.co/facebook/wav2vec2-xlsr-53-espeak-cv-ft and https://github.com/huggingface/transformers.js .

Confidence update: events below 0.35 are ignored; selected evidence needs average confidence >=0.5 and dominance >=0.7, with a veto for competing events >=0.85. These thresholds are experimental, not calibrated guarantees. Signal evidence can advance travel up to 70% while listening (including unvoiced stop bursts). Recognition gives further partial progress; only validated identity plus required duration/repetitions reaches 100 and reward.
