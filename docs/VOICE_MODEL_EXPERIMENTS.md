# Проверка дообучения голоса — 2 октября 2026

Модель не включена в приложение: распознавание протяжных гласных остаётся нерешённым. UI-исправления можно проверять и публиковать отдельно. Agentic AI помогает организовать эксперименты, но не заменяет фонетическую разметку.

## Реальное дообучение

Дообучен последний Transformer-блок CUPE MSWC38 и новая голова на десять классов; предыдущие блоки заморожены. Источник — [Tabahi/CUPE-2i](https://huggingface.co/Tabahi/CUPE-2i), revision `772503ad6605916b88b81b1855f81533243069be`, GPL-3.0. Исследовательские веса не включены в репозиторий или сборки.

[WorldVowels](https://docs.cognitive-ml.fr/perceptimatic/data/WorldVowels/) (CC0): 1110 train / 465 validation, независимые говорящие; отдельный sealed-набор не использовался. Обучение действительно обновляло энкодер: 13 эпох, early stopping, лучший результат на эпохе 8. Выбранная пользователем буква не передавалась классификатору.

Точность — **29,68%**. Для О precision/recall — 29,55% / 52%; У — 37,21% / 32%; Ү — 45,16% / 28%. При пороге 0,8 правильно принято 0/50 примеров каждого из этих трёх звуков; при 0,5 — 1/50 О, 0/50 У, 1/50 Ү. Снижение порога не решает проблему.

Независимые отрицательные fixtures: тишина, шум, синусоиды 120/220/440/880 Hz и гармонический сигнал 220 Hz. При пороге 0,8 принятых окон нет, но положительные примеры также почти не принимаются. При 0,5 синусоида 880 Hz классифицируется как А; этот тест модели не считается доказательством ложной награды в приложении, где есть отдельный фильтр голосового сигнала.

## Проверенные новые корпуса

- [Zurich Corpus, первичные условия](https://zhcorpus.org/v1/doc/Terms.pdf): scientific-only доступ и обязательное удаление после исследования; для релизного обучения не использован.
- [Friedrichs et al. 2026](https://www.nature.com/articles/s41597-026-07704-3), [версия данных](https://doi.org/10.48656/vc7s-pt02): CC BY 4.0 подтверждена API и README. Через ограниченные HTTP Range скачаны два WAV общей величиной 4,85 MB вместо архива 138 GB. В них восемь фонаций около 0,31–0,41 секунды; отдельной буквенной разметки нет. Данные не использованы для обучения, порядок букв не угадывался. Этот пилот не доказывает отсутствие более длинных примеров во всём корпусе.
- [MSDOC, статья](https://doi.org/10.1038/s41597-026-07214-2), [депозит](https://doi.org/10.57760/sciencedb.28429): официальный API вернул `PERMISSION NO ACCESS`; аудио не скачивалось, разрешённая лицензия набора не предполагалась из лицензии статьи.

## Что требуется для рабочего решения

Нужны разрешённые естественные протяжные записи с достоверной разметкой буквы и интервалов, разделением говорящих между train/validation/test и отрицательными примерами. Распознаватель должен независимо определять звук в каждом временном окне. Детскую и атипичную речь необходимо проверять отдельно. Короткий правильный звук вместе с двумя секундами произвольного голоса не подтверждает протяжную выбранную букву.

Скрипты, метрики, контрольные суммы и исследовательские веса сохранены вне проекта в локальной папке `inclusiveapp-qa`; пользовательские записи не сохранялись и не отправлялись.
