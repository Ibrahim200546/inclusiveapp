# InclusiveApp: ремонт и проверка

Дата: 1 октября 2026. Исходная версия: `ab719125927eebd49ae26709bab9478cffa30e64`.
Ветка: `repair/voice-learning-responsive`. Изменения подготовлены в отдельной копии;
публикация, push и изменение рабочего сайта не выполнялись.

## Важный итог

Основные ошибки исправлены в коде и покрыты автоматическими проверками. Это **не
полный релизный допуск**: реальный браузер, живой микрофон и прослушивание записей
недоступны в текущей среде. Для қобыза и сыбызғы ещё нужны достоверные разрешённые
аудиозаписи. Эти ограничения не подменены успешными тестами или чужими звуками.

## Слова

Оригинальные `sounds/syllables/word_1.mp3`…`word_4.mp3` не изменены. Их содержимое
не выдаётся за заново расшифрованное или прослушанное; сохранена исходная привязка
к количеству слогов.

| Слогов | Пять новых слов |
| --- | --- |
| 1 | ат, доп, нан, шар, су |
| 2 | алма, бала, қалам, балық, шана |
| 3 | балалар, ойнады, сыпырды, тақия, оянды |
| 4 | құрастырды, ұйықтады, балабақша, кітапхана, ойыншықтар |

Нет отдельной записи для: **ат, нан, шар, балабақша, кітапхана, ойыншықтар**.
Запись «ш шар» не используется для подсчёта слогов: она может содержать название
буквы перед словом. При отсутствии установленного локального казахского голоса
интерфейс явно предлагает прочитать слово. Это доступный резервный режим,
а не подтверждение выполнения слухового задания. Для 100% аудиопокрытия нужны
эти шесть записей. Русский голос вместо казахского не подставляется.

## Что не было проверено

- Реальные viewport screenshots, pixel bounds, hover/active и отсутствие
  перекрытий на устройствах. Запуск Chromium запрещён средой (`socket():
  Operation not permitted`); штатный cloud-browser доступ к локальному preview
  также заблокирован. Скриншотов приложения после исправлений нет
- Живой голос ребёнка/взрослого, микрофон, железо, разные браузеры, mobile WebView,
  слуховое качество и точный текст исходных записей
- Вход/регистрация, приватные профили Supabase, сохранение монет, административные
  экраны, Telegram, облачные AI/STT/TTS поставщики и их credentials; данные учеников
  не использовались
- APK/iOS/Windows сборка и нативные автообновления; CI, push, deploy не запускались
- Произношение и клиническая/логопедическая валидность. Новый голосовой детектор
  эвристический; музыка и чужой голос могут дать сигнал, что написано в UI

## Продолжение проверки в обычной среде

Установить зависимости из lockfile и запустить `npm run dev`. Проверить
`/original/index2.html`. Порт берётся из вывода Vite. Для автоматических снимков:

```bash
BASE_URL=http://127.0.0.1:8080 QA_OUTPUT=./qa-layout node scripts/check-responsive-layout.cjs
```

Требуется доступный Playwright/Chromium. При установленном в другом месте
Playwright можно передать `PLAYWRIGHT_MODULE`, для браузера `CHROMIUM_PATH`.
Скрипт проверяет пять ширин, центр idle/hover/active, клавиатуру, возврат,
инструменты и слоги; делает 25 снимков. Реальный микрофон проверяется отдельно:
разрешить/отказать, говорить/молчать, остановить, открыть снова, уйти назад во
время запроса разрешения, отключить устройство и проверить освобождение индикатора.

## Оставшиеся зависимости

См. `SECURITY_AUDIT.md`. Показатели npm audit относятся к дереву зависимостей,
а не к количеству доказанных эксплуатируемых ошибок приложения. Не открывать
необновлённый dev/test server в недоверенную сеть; миграции Vite/Vitest/Router
нужно проверять отдельно в доступном браузере и нативных сборках.
