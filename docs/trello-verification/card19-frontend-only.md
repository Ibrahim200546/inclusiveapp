# Карточка №19: фронтенд без рабочего бэкенда

Владелец подтвердил: Supabase рабочего InclusiveApp отключён намеренно. Базовый релиз должен открывать учебные упражнения как статический сайт; не следует восстанавливать базы, проверять старые боевые миграции или включать webhook ради закрытия прежних критериев.

- Vercel обслуживает статические файлы и известные маршруты сайта; бывшие `/api/ai-chat`, `/api/ai-evaluate`, `/api/tts` больше не являются Vercel Functions. Локальный Vite возвращает 404 на старые API. Релиз больше не включает Docker-обвязку, запускавшую собственный сервер.
- Исходники и тесты прежних API доступны в истории Git до перехода на фронтенд; они удалены из текущего релиза и не развёртываются. Резервные коды и локальный прогресс не удалялись. Supabase и другие серверы не перенастраивались.
- Новая проверка подтверждает HTTP 404 для старых API и наличие страницы упражнения и образца барабана. Для полной приёмки фронтенд-релиза отдельно проверять основные переходы и локальное сохранение без обращения к backend.
- Первичная загрузка публичных статических файлов модели распознавания остаётся возможной; сама запись фонем обрабатывается на устройстве. Это не проверка полного офлайн-режима при пустом кэше.
