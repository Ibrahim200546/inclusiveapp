# №04: близкие звуки, техническая проверка

Основание: [карточка №04](https://trello.com/c/JlzX3w5Q), её перечень 30 пар и указанная в карточке таблица 8 / 1.2.1.5. Базовые тексты сверены с `contrast-drafts.json` и `content-approval.json`; дополнения Ұ–У, Қ–Х и Қ–Һ имеют отдельную запись интеграции от 12.11 в `contrast-card30-additions.json`. Разрешение публиковать подготовленные примеры не равно заключению методиста о произношении.

| Критерий | Результат |
|---|---|
| Исходный список | Все 30 пар присутствуют под точными буквами, 33 пары с отдельно отмеченными дополнениями. У каждой 2 слога, 2 слова, 2 предложения; всего 198 шагов. Для прежнего самостоятельного каталога 2 класса заключения не делаем: его публичный вход теперь использует программу 0–1 по №38. |
| Текст и аудио | Сверены текст стимула, варианты, правильный ответ, текст и SHA-256 в манифесте для всех 198 шагов. FFmpeg декодировал 106 уникальных MP3 без ошибок. Это подтверждает техническую целостность, не фонетику. |
| Вход и поиск | Chromium: реальный путь «Класс → Произносим → группа звуков → пара»; поиск О–Ө/Ө–О; переключение уровня и два независимых образца. |
| Сброс аудио | Смена пары, уровня, режима или запроса останавливает прежнее воспроизведение. «Бастау» запускает выбранную практику; её выбор заблокирован до прослушивания. Проверено на ширине 360 px. |
| Устный режим | Отметка педагога недоступна до образца и сохраняется отдельно, без заявления автоматической оценки речи. |
| Методическая и очная приёмка | Не выполнена. Сверить каждый образец на слух, соответствие визуальной подсказки и уровень сложности, пройти сценарий на физическом телефоне и компьютере. |

### Первоочередное прослушивание методистом

| Контраст | Слова, которые сейчас получает ученик |
|---|---|
| А–Ә | ана / әже |
| О–Ө | от / өт |
| У–Ү | су / күн |
| Ү–Ұ | күн / ұн |
| Ө–Ү | өрік / үй |
| Ы–І | ыдыс / ін |
| І–И | ін / ине |
| К–Қ | кесе / қоян |
| Г–Ғ | гүл / ағаш |
| К–Һ, Х–Һ | кесе / қаһарман, хат / қаһарман |
| Ұ–У, Қ–Х, Қ–Һ | ұн / су, қоян / хат, қоян / қаһарман |

Кроме от–өт эти строки не объявляются минимальными парами. Проверять отдельно наличие целевого звука, артикуляцию в записи, соответствие текста и изображения или нейтральной пиктограммы, возрастную сложность. Для непрошедшего примера указать пару, уровень, сторону, причину и предложенную замену; не подставлять название буквы вместо слога.
