# 🎧 Сиқырлы Дыбыстар Әлемі — Инклюзивті Оқыту Платформасы

Бұл жоба есту қабілеті бұзылған және сөйлеу тілінде мүкістігі бар балаларға арналған заманауи интерактивті оқыту қосымшасы. Ойын түріндегі тапсырмалар арқылы балалар дыбыстарды ажыратуды, сөздерді дұрыс айтуды және есту қабілетін дамытуды үйренеді.

## 🌟 Жобаның Мүмкіндіктері

### 📚 Оқу Деңгейлері
Бағдарлама 5 деңгейге бөлінген:
- **Дайындық тобы (0-сынып)**: Дыбыстар әлемімен алғашқы танысу.
- **1-4 сыныптар**: Күрделі тапсырмалар, сөздік қорды дамыту, музыкалық ырғақ және логикалық ойындар.

### 🎮 Интерактивті Ойындар
- **Дыбысты Тап**: Жануарлардың, көліктердің және тұрмыстық заттардың дыбыстарын ажырату.
- **Музыкалық Аспаптар**: Аспаптардың үнімен танысу.
- **Ырғақ және Темп**: Музыкалық қабілетті дамыту.
- **Артикуляциялық Карта**: Дыбыстардың жасалу жолдарын көрсететін интерактивті сызба.

### 🎨 Дизайн және Ыңғайлылық
- **Glassmorphism**: Заманауи, әдемі және жеңіл дизайн.
- **Күндізгі/Түнгі режим**: Көру қабілетін сақтау үшін интерфейсті бейімдеу (күндізгі режимде ашық фон, түнгі режимде қараңғы фон).
- **Анимациялар**: Балалардың назарын аударатын қызықты қимылдар.

## 🛠 Технологиялар

Жоба келесі заманауи технологиялар негізінде жасалған:
- **React**: Пайдаланушы интерфейсін құруға арналған кітапхана.
- **TypeScript**: Код қауіпсіздігі мен сапасын қамтамасыз ету.
- **Vite**: Жылдам құрастыру және іске қосу құралы.
- **Tailwind CSS**: Стильдерді икемді және жылдам жазу.
- **HTML5 Audio API**: Дыбыстық файлдармен жұмыс.

## 🚀 Орнату және Іске Қосу

Жобаны өз компьютеріңізде іске қосу үшін төмендегі қадамдарды орындаңыз:

### 1. Жүйелік Талаптар
- **Node.js** (v22.12 немесе одан жоғары) орнатылған болуы керек.

### 2. Жобаны Көшіріп Алу
Терминалды ашып, келесі пәрмендерді енгізіңіз:

```bash
# Репозиторийді клондау
git clone https://github.com/Ibrahim200546/inclusiveapp.git

# Жоба папкасына кіру
cd inclusiveapp
```

### 3. Кітапханаларды Орнату
Қажетті тәуелділіктерді (dependencies) орнату:

```bash
npm install
```

### 4. Жобаны Іске Қосу
Дамыту режимінде (Development mode) іске қосу:

```bash
npm run dev
```

Осыдан кейін браузерде `http://localhost:8080/` (немесе терминалда көрсетілген басқа порт) мекенжайын ашыңыз.

## 📂 Ескі Нұсқа (Original Demo)

Бұл жобада қосымшаның алғашқы **HTML/JS** нұсқасы да сақталған. Оны көру үшін:
1. Басты беттегі **"Ескі нұсқасын қосу (Original Demo)"** сілтемесін басыңыз.
2. Немесе тікелей мына сілтемеге өтіңіз: `http://localhost:8080/original/index2.html`

Ескі нұсқа React-қосымшасымен толықтай біріктірілген және ортақ `assets` (суреттер мен дыбыстар) папкасын қолданады.
